# MCP surface: small `/mcp`, full list at `/mcp/all`, real integer ranges, one tool count, free calls per connection (16 Nov 2026)

Stopped early on the owner's budget stop. The code for all six sub-items is written; the full `npm test` was NOT run on the final tree.

- **1. Small `/mcp` (done).** `/mcp` and `/mcp/k/<key>` list 15 tools (29.5 KB): `find_tool`, `describe_tool`, `call_tool` (`SURFACE_TOOLS`) plus `MCP_PINNED_PATHS` in src/mcp-contract.ts: /search, /extract, /news, /weather, /price/token, /sanctions/check, /check/payee, /transcribe, /pdf/text, /company/search, /vat/validate, /ai/chat. src/mcp.ts `handleMcp` (`small`, `surfaceHow`, `surfaceDefinition`) and `registerCompactTools(..., surface)`. `tool_details` also answers on `/mcp`; `/mcp/compact` and `/mcp/compact-capped` are untouched.
- **2. Any old name still runs on `/mcp` (done).** Every tool is still registered; only the list handler changed. tests/mcp-surface.test.cjs calls an unlisted tool by name with the real SDK client and compares it with `/mcp/all` (answer, free-call note, payment request, funnel row).
- **3. `/mcp/all`; entry paths unlisted, still callable (done).** `ALL_BUNDLE`; `listable` in `handleMcp`; `mcpListed` in src/discovery.ts. `mcpInstallLinks().full`, README, llms.txt line, llms-install.md, the openclaw skill (both copies), server card (`fullList`), scripts/build-registry-manifests.mjs (new `all` manifest) and the npm client's `--full` (repo copy only, version not bumped) say `/mcp/all`. server.json `remotes` stays `/mcp`.
- **4. Integer ranges (done).** `integerRange` + `toolInputShape(..., listed)` in src/mcp-contract.ts: the range the input's description states (widened by "up to N"), else a range by input name read from the handlers (`INTEGER_KINDS`), else -1e12..1e12. Listing only: calls are checked against the unbounded shape as before. scripts/check-mcp-contract.mjs pins the listed schema.
- **5. One count (done).** `TOOL_COUNT` in src/endpoints.ts = tools without entry paths = **656** (725 paid paths, 69 entry paths; `/mcp/all` lists 425, the other 231 are the extra networks' chain reads). Used by `SERVICE_SUMMARY`, MCP instructions, server card (`toolCount`), `PAGE_TITLE`, both home pages, `/tools` and the "All N tools" footers. README.md and server.json are pinned through scripts/bump-version.mjs (new kind `toolCount`; `mcpCount` is now the `/mcp/all` list) and tests/tool-count.test.cjs.
- **6. Free calls per connection (done).** src/lib/free-sessions.ts (`freeSessionFor`): at `initialize` an unpaid, keyless connection gets `Mcp-Session-Id` = `<32 hex id>.<HMAC-SHA256>`; the key is made once and kept in the Metrics object "credits" (`freeSessionSecret`), so no secret is needed. `takeSessionFreeCall` in src/lib/free-calls.ts counts on the token; an address admits `FREE_SESSIONS_PER_ADDRESS_PER_DAY` = 3 new tokens per UTC day, later ones and forged ones are counted on the address; a used-up token does not fall back; the 2,000-a-day total is unchanged. Issuing writes nothing.
