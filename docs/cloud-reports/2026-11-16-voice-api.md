## Voice API for apps leaving OpenAI's tts-1 and whisper-1 (branch cloud/20261116-voice-api, 16 Nov 2026)

- Why: OpenAI's deprecations page (read 16 Nov 2026) shuts down `tts-1`, `tts-1-hd` and `gpt-4o-mini-tts` on 6 Jan 2027 and `whisper-1` with the gpt-4o transcribe models on 26 Feb 2027. Apps with an "OpenAI-compatible" speech setting need a new base URL; the move happens only if the first test call is cheap and the errors read like sentences.
- **Key prices on the fronts** (`src/lib/voice-billing.ts`; prepaid keys only, x402 and MPP quotes unchanged because a $0.001 on-chain settlement nets nothing):
  - `POST /v1/audio/transcriptions`: audio of 30 s or less costs 1 credit. MP3 and WAV are measured from the bytes before the charge (`measuredSeconds` in `src/lib/voice-fronts.ts`, built on `mp3Frames` and `wavInfo`); the front marks the tool request with `setFrontKeyPrice` and the paywall line in `src/index.ts` reads it with `frontKeyPrice` (a WeakMap keyed by the Request, so no header can set it; it can only lower a price). Any other format is charged the tool price and `rebateShortAudio` gives 9 credits back only when the model's own `durationSeconds` is 30 or less (`rebateCredits` in `src/lib/credits.ts` and the Metrics object: balance up, spent down, call count untouched). No reported length: the tool price stands.
  - `POST /v1/audio/speech`: `SPEECH_CREDITS_PER_100` = 4 credits per started 100 characters, capped at the tool's flat price (201-300 characters cost 10, not 12; 2,000 cost 80 as before). Aura-2 costs 3 credits per 100 characters, so no length is below cost and none costs more than before. **The rate is a price for the owner to confirm**; no plan document names one. Catalog prices and the freeze file are unchanged.
  - The ElevenLabs-shaped fronts and the tools themselves charge as before. The fronts now pass `X-Credits-Charged`, `X-Credits-Remaining` and the other key headers through (they were dropped on 200 answers). Both rules are stated in the OpenAPI descriptions (`speechKeyRule`, `SHORT_AUDIO_KEY_RULE`).
- **`GET /v1/models`** adds `audioModels()` (`src/lib/openai-voices.ts`): the two models that run and `whisper-1` / `tts-1` as accepted names with `alias_of` and a note that they are not OpenAI's models; an `audio` block links the voice list, `/credits` and, when on, the test key route. Always 200, CORS open, like `GET /v1/audio/voices`.
- **Key refusals** (`unknownKey` and `chargeCredits` in `src/lib/credit-routes.ts`): the `error` text now starts with a sentence ("This API key is not recognised, so nothing was charged. ..." / "This key does not have enough credits for this call: ...") and a `code` follows (`invalid_api_key`, `insufficient_credits`); status codes, `buy`, `topUp` and `freeKey` are kept. The voice fronts rewrite these into the caller's shape (`asFrontKeyError`: OpenAI `{error:{message,type,code}}`, ElevenLabs `{detail:{status,message}}`). A key from elsewhere (an OpenAI key left in the SDK) still gets the 402 quote, because x402 clients send placeholder keys; its `error` text starts with a sentence (`withSentenceFirst`) and every payment field is unchanged. Two tests pinned the old wording and were updated (tests/credits.test.cjs, tests/credit-plans.test.cjs). MCP wording is untouched.
- **Free keys** (`src/lib/voice-keys.ts`; routes `voiceKeys`, paywall branch `chargeVoiceKey`, front check `admitVoiceKey`). Keys look like `adt_vt_…` / `adt_tr_…` (46 characters after `adt_`, so never a purchased key). Only a hash of the key and of the address (IPv4, or the IPv6 /64) is kept in KV for at most two days. Calls are counted exactly with the free-call counter of the Metrics object under their own names; nothing is written to the credit ledger, so /revenue and the funnel do not see them. Privacy text added in `src/lib/legal.ts`.
  - `POST /keys/voice-test` (`VOICE_TEST_KEYS`): 25 successful calls in 24 hours, speech up to 100 characters, MP3 or WAV up to 30 s, one key per address per day, `VOICE_TEST_KEYS_PER_DAY` (100) keys a day, 1,000 speech calls a day over all test keys, 2,000 counted calls a day (exact). Worst day about $3.50, never above $6. Works only through the four voice fronts.
  - `POST /credits/trial` (`CREDITS_TRIAL`): one uploaded file per address per UTC day, at most 30 minutes (longer is refused before any model call), key valid 2 hours and never past the UTC day, `CREDITS_TRIAL_MINUTES` (200) a day. Minutes are taken when the length is known and given back when the call fails; a format that cannot be measured (up to 5 MB) is counted after it ran. Worst day about $0.15. Works on the transcription fronts and, because the voice site uploads straight to the tools, on a file POSTed to `/transcribe/long` or `/transcribe` (`admitTrialUpload`). CORS is the Worker's `*`.
  - **Both are "off" in wrangler.jsonc and "on" in wrangler.staging.jsonc.** The limits are tested against the real Metrics object and KV in Miniflare, never against real Workers AI. The KV counters (keys a day, speech calls, minutes) are approximate in a burst; the per-key and per-address counts are exact.
- Tests: tests/voice-api.test.cjs (9 tests: whole Worker in Miniflare, a fake AI as a service-binding entrypoint, KV, a card pack claimed through a faked Stripe read).
- For the voice site: `docs/voice-site-patches/` (README there). The patch is a real diff against the live transcribe.js fetched once on 16 Nov 2026; it applies cleanly and passes `node --check`, and was not run in a browser.
- Guides, what was read on which page on 16 Nov 2026: OpenAI's dates (its deprecations page); Lemonfox prices, limits and formats (lemonfox.ai home, /apis/speech-to-text, /apis/text-to-speech); Groq Whisper prices, 10-second minimum, file sizes and answer formats (console.groq.com/docs/speech-to-text) and its Orpheus endpoint (docs/text-to-speech; no price on that page, so none is given); Together's Whisper and Kokoro prices (together.ai/pricing, /models/kokoro-82m); Kokoro-FastAPI's endpoint, formats and languages (its README). Not readable that day and written as "see their pricing page": OpenAI's own whisper-1 and tts-1 prices, Groq's speech price, Together's upload limits.
